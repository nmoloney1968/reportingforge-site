Changelog Milestones on the way to launch

What is changing as Reporting Forge takes shape.

This changelog tracks how Reporting Forge evolves - first as a book and lab, and later as tooling. It starts long before any installable product exists, so you can see where effort is going and how ideas change over time.

2025-11 - Refocus on book and lab

Updated the public site to reflect the real first step for Reporting Forge: a structured learning path from manual spreadsheets to a small Python and Power BI reporting stack with AI as a helper. Roadmap and docs adjusted to emphasise teaching patterns before building hosted tooling.

2025-10 - Domain and initial positioning

Registered reportingforge.com, set up email and Cloudflare, and drafted the first narrative around a thin reporting automation layer. Early conversations with potential users highlighted the need to start with educational material rather than a fully fledged platform.

This will grow slowly and honestly over time. When a hosted tool becomes real, the changelog will also include version based releases and upgrade notes.
