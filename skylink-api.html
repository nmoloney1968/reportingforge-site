SkyLink Test Network

SkyLink sandbox API

This is a small, read only API designed for the Reporting Forge book. It lets you practise calling an API, pulling JSON data into Python, and building automated reports - without touching any production systems.

Base URL

All examples in the book use the following base URL (replace yourdomain.com with the real domain where the site is hosted): 

https://yourdomain.com/api/skylink/

Endpoints are simple static JSON files. Treat them exactly as you would a normal HTTP GET API.

GET /sites.json

Returns the list of SkyLink test sites and their basic attributes.

Example URL:

https://yourdomain.com/api/skylink/sites.json

Useful for: joining site metadata onto usage and alerts in your scripts and reports.

GET /usage-daily.json

Returns a small window of daily usage data for each test site.

Example URL:

https://yourdomain.com/api/skylink/usage-daily.json

Fields include date, site id, total usage in GB, and a split between peak and off peak.

GET /alerts.json

Returns recent alerts for the test sites (for example, usage trending high or a site being suspended).

Example URL:

https://yourdomain.com/api/skylink/alerts.json

Example Python snippet

In the book you will use AI to generate code like this, but it is helpful to see the shape of the calls:

import requests

BASE_URL = "https://yourdomain.com/api/skylink"

resp = requests.get(f"{BASE_URL}/sites.json")
resp.raise_for_status()

data = resp.json()
print(data["sites"][0])
