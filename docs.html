Technical notes

How the examples are wired together

The book is designed so that you can follow the examples on a modest laptop with minimal setup. AI generates most of the code, and you focus on understanding the flow and adapting it to your own reporting work.

What you will be using

  • Python 3 – installed locally, using IDLE or another simple editor.
  • Requests – a small HTTP client library used in the API examples.
  • Power BI Desktop – for shaping data and building visuals.
  • The SkyLink Test Network sandbox API – a tiny, read-only JSON API.

You do not need to memorise APIs, libraries, or syntax. The book gives you short prompts you can paste into your AI assistant (including all of the context it needs) so that it can write the first draft of each script or measure.

SkyLink sandbox API

All of the API examples use the same base URL: 

https://reportingforge.com/api/skylink/

Endpoints are documented in more detail on the SkyLink API reference page, but in practice you will mostly be calling:

  • sites.json – the list of test sites.
  • usage-daily.json – daily usage per site.
  • alerts.json – example alerts and notifications.

Typical Python pattern (for AI to generate)

This is the basic shape of the code you will use. In the book, you will ask AI to generate and then refine it, rather than typing it all by hand: 

import requests

BASE_URL = "https://reportingforge.com/api/skylink"

resp = requests.get(f"{BASE_URL}/usage-daily.json", timeout=30)
resp.raise_for_status()

usage = resp.json()["usage"]

Adapting the examples to your own APIs

One of the goals of the book is that you can apply the same patterns to the APIs your organisation already uses: finance systems, CRM, project tools, or analytics platforms.

Each time we use the SkyLink sandbox, the book also includes a short sidebar that shows you:

  • where to find API documentation on a typical SaaS platform,
  • which pieces of that documentation to paste into AI, and
  • how to plug your own API keys or URLs into the generated code.

Scheduling and automation

The first edition focuses on getting one complete workflow running reliably from your laptop. Toward the end of the book, we look at how to take that same script and:

  • run it on a simple schedule using your operating system, and
  • prepare it for a later move into a more formal environment, if you need one.
