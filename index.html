30 day AI first workflow for real business reporting

Build automated reports with almost no coding

Reporting Forge is a practical book and sandbox that shows you how to use AI, Python, APIs, and Power BI together to automate one real reporting workflow from end to end. AI writes most of the code – you steer.

You will not be hand-writing long Python scripts or complex DAX.
You learn how to ask AI for the code you need, then adapt and verify it.
You practise on the SkyLink Test Network – a small, safe API built just for this book.

No prior Python or Power BI experience is required – just curiosity and a reporting problem you care about.
What you will work with
Inside the 30 day plan
  • Short daily prompts you can paste into your AI assistant.
  • A tiny Python toolbelt: requests, a few data transforms, and file output.
  • The SkyLink sandbox API for realistic but safe data.
  • A Power BI report that you grow step by step.
What you will ship
  • One automated workflow that fetches data from an API, cleans it, and feeds a report.
  • A reusable prompt library for AI that you can adapt to other reports.
  • A clearer sense of when you need a “real platform” and when a few scripts are enough.

The SkyLink API docs are public, so you can start inspecting the sandbox even before the book is finished.
